# Canonical Course and Report publication checks

Last updated: 2026-11-06

This implements the next [publication boundary](workspace-publication.md), after
separately accepted private saving and exclusive artifact creation. Alvaro's
standing "I approve everything / Keep going / Do all the work" covers the necessary
local-provider source, public access behavior and bounded disposable CI. No paid
plan, new account, hosted configuration, production data or model call is involved.

Publish is an explicit confirmation for a saved revision. Apply/local editing
does not publish. The server reauthorizes current legacy session/member roles
before preparing and committing. Existing receipt rows bind request/version UUIDs,
payload, original live pointer and preparation time. A different draft or live
pointer ends in conflict. Version, pointer and final receipt commit atomically;
replays report the original receipt alongside current state. Viewers can read
private publication status but cannot publish; passwords and Slides remain outside
this new publication path.

One exclusive canonical JSON object retains the original HTML, compiler manifest,
binding, raw HTML hash and script-hash CSP. Same-intent recovery reads/verifies it
without recompiling through a later renderer. Raw object/HTML hashes and canonical
compiler hashes retain distinct meanings. Put/commit uncertainty never triggers
object deletion. A reserved namespace and decoded traversal guard keep staged
objects inaccessible through the legacy raw-file route, including overlapping
storage roots. Only a committed, owned published version has a canonical reader.

`/v/{publicId}` is a no-store relative redirect to its current version;
`/v/{publicId}/{versionId}` serves the stored verified snapshot with revalidation,
nosniff and stored CSP. Working drafts stay separate from earlier published bytes.
Public Course progress is scoped to public/version/lesson IDs and tolerates denied
storage. Quiz feedback works without the unsupported legacy analytics endpoint.
The new publication renderer is explicit; existing preview/default modes remain.

The focused source contains fourteen T2 HTTP/staging/delivery cases, six T2 client
protocol cases, twenty T3 real PostgreSQL cases, and four actual Course/Report
desktop/narrow Chromium journeys. Browser fixtures create private documents through
the actual authenticated API, then publish via explicit UI confirmation. Anonymous
contexts read actual committed artifacts, retain original version bytes after a
second publication and verify draft/public separation and learner behavior. No
generation, publication, database or artifact response is fulfilled. The bounded
native-fetch response-clone observer retains real request/response behavior.

The temporary public Ubuntu job pins Node 24.21.0, PostgreSQL 17.6 and the unchanged
frozen lock, with a 20-minute cap. Original bounded command streams/JSON, exact
names/statuses, native/index/mode/content guards, actual readiness and owned
process/port/marked-database/scratch closure must pass. Header-qualified streamed
navigation cancellations remain separate observations after completed transitions.
Unknown errors/resources fail; failed attempts remain. No closed suite is rerun.
Temporary CI is QA-only and disabled/retired afterward; permanent CI is retained.

Attempt 1 passed all forty core cases and narrow Course, while desktop sign-in
and two Report request-failure boundaries remained incomplete. Its failed overall
receipt is preserved. The publisher now releases completed reads before exposing
UI state and aborts only pending work. Attempt 2 carries the original forty
passes with all 36 original captures and 268 protected runtime inputs; only the
shared publisher changes. The old browser pass is historical, so all four browser
identities require current-source acceptance. An anonymous bounded workspace
readiness probe requires the existing redirect to `/auth`; browser assertions,
timeouts and cancellation rules stay unchanged. No application auth fix is claimed.

Fresh host Storage Guard measured 17.8 GiB free against 34.0 required. No local
install, build, database, server or browser runs. This verifies the local canonical
publication slice; hosted Supabase/Auth/RLS/storage, original assets, physical
devices/touch, full analytics/AI/Eve and full-product acceptance remain separate.
Production remains held on its prior source until reviewed hosted configuration
exists; the earlier environment403 is not retried or bypassed.
